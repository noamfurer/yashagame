# השעשועון הגדול של שחר ויהלי 🎉

שעשועון בסגנון לוח קטגוריות טלוויזיוני ליום ההולדת העשירי של שחר ויהלי.

- פותחים את `index.html` בדפדפן, לוחצים **F** למסך מלא.
- **רווח**: חשיפת תשובה · **1** / **2**: נכון / לא נכון · **T**: החלפת הקבוצה שעונה · **Esc**: חזרה ללוח · **M**: השתקה
- עריכת שאלות: גלגל השיניים בתחתית המסך.
- השאלות נמצאות גם בראש הקוד, במערך `QUESTIONS`.
